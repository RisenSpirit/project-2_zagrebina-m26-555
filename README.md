# Примитивная база данных

Консольное приложение на Python, имитирующее простую реляционную базу данных.
Позволяет создавать и удалять таблицы, добавлять, читать, обновлять и удалять
записи. Метаданные таблиц хранятся в `db_meta.json`, данные каждой таблицы —
в отдельном файле `data/<имя_таблицы>.json`.

## Установка

Требуется Python 3.12+ и [Poetry](https://python-poetry.org/).

```bash
git clone git@github.com:RisenSpirit/project-2_zagrebina-m26-555.git
cd project-2_zagrebina-m26-555
make install
```

## Запуск

```bash
make run
```

После установки пакета (`make build` и `make package-install`) база данных
запускается командой:

```bash
database
```

Проверка кода линтером:

```bash
make lint
```

## Управление таблицами

| Команда | Описание |
|---|---|
| `create_table <имя> <столбец1:тип> <столбец2:тип> ...` | создать таблицу |
| `list_tables` | показать список всех таблиц |
| `drop_table <имя>` | удалить таблицу (с подтверждением) |
| `help` | справочная информация |
| `exit` | выход из программы |

Поддерживаемые типы: `int`, `str`, `bool`. Столбец `ID:int` добавляется
автоматически первым.

```
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool
>>>Введите команду: list_tables
- users
```

## CRUD-операции

| Команда | Описание |
|---|---|
| `insert into <имя> values (<знач1>, <знач2>, ...)` | создать запись |
| `select from <имя>` | прочитать все записи |
| `select from <имя> where <столбец> = <значение>` | прочитать записи по условию |
| `update <имя> set <столбец> = <значение> where <столбец> = <значение>` | обновить запись |
| `delete from <имя> where <столбец> = <значение>` | удалить запись (с подтверждением) |
| `info <имя>` | вывести информацию о таблице |

Правила ввода значений:

- строки — только в кавычках: `"Sergei"`;
- числа — без кавычек: `28`;
- логические значения — `true` / `false`;
- значение `ID` не указывается, оно генерируется автоматически;
- все поля обязательны.

```
>>>Введите команду: insert into users values ("Sergei", 28, true)
Запись с ID=1 успешно добавлена в таблицу "users".
Функция insert выполнилась за 0.001 секунд.
>>>Введите команду: select from users where age = 28
Функция select выполнилась за 0.000 секунд.
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  28 |    True   |
+----+--------+-----+-----------+
>>>Введите команду: update users set age = 29 where name = "Sergei"
Запись с ID=1 в таблице "users" успешно обновлена.
>>>Введите команду: delete from users where ID = 1
Вы уверены, что хотите выполнить "удаление записи"? [y/n]: y
Запись с ID=1 успешно удалена из таблицы "users".
>>>Введите команду: info users
Таблица: users
Столбцы: ID:int, name:str, age:int, is_active:bool
Количество записей: 0
```

## Обработка ошибок и декораторы

- **`handle_db_errors`** — централизованно перехватывает ошибки
  (`KeyError`, `ValueError`, `FileNotFoundError`). Программа не падает,
  а выводит понятное сообщение:
  ```
  >>>Введите команду: select from nope
  Ошибка: Таблица или столбец 'nope' не найден.
  >>>Введите команду: insert into users values (Sergei, 28, true)
  Ошибка валидации: некорректное значение Sergei. Строки должны быть в кавычках.
  ```
- **`confirm_action`** — запрашивает подтверждение перед опасными операциями
  (`drop_table`, `delete`). Любой ответ, кроме `y`, отменяет операцию:
  ```
  >>>Введите команду: drop_table users
  Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: n
  Операция отменена.
  ```
- **`log_time`** — выводит время выполнения `insert` и `select`.
- **`create_cacher`** — замыкание, кэширующее результаты одинаковых
  запросов `select`.
